 # Propósito
 Documentar los requerimientos funcionales y no funcionales para desarrollar una plataforma web y móvil que permita gestionar y dar visibilidad a las ferias locales de Bahía Blanca.

 Como premisa fundamental, el sistema buscará respaldar activamente a los feriantes que mantengan un compromiso constante con las convocatorias, cumplan con las normativas regulatorias y consoliden su actividad como un negocio formal y saludable para el crecimiento de minipymes y emprendedores regionales.
